## 🔬 TRIAGE — ReplayCoach (Run #5, hotbox, "cleanest WTP logic to date")

> AI-drafts coaching reviews + drills for solo esports coaches from
> structured match data, in the coach's own voice — so they bill more
> students in the same hours.

**Gating kill question (from memory):** Is the population of solo esports
coaches with paying rosters big enough for a 500-user capped launch
without owning >5% of the niche? Plus freshness rule: re-scan competitors.

**Finding — KILL. Both axes now resolve against it:**

### 1. Niche too small — the original gate fails
The esports-coaching *services* market is real ($325–600M in 2024,
growing ~15–20% CAGR), but that is mostly the value of coaching delivered,
not the count of solo coaches who would buy a $15–25/mo SaaS tool. The
actual buyer population is thin: Metafy — the flagship platform — built
its model on *curated top talent* (~300 coaches as of 2021, deliberately
exclusive), and across Metafy + Gamer Sensei + ProGuides + independents
the serious, paying-roster solo coach population is still low-thousands
globally. A 500-user capped launch would need to own well over 5–10% of
essentially the entire serious-coach profession — the same niche-size wall
that killed MatchLoop (#7, ~2–3k matchmakers). The gate the factory set in
Run #5 closes against ReplayCoach.

### 2. Freshness re-scan — the mechanism is now commoditized + free-undercut
In Run #5 (2026-06-09) the coach-facing "auto-draft the review from match
data" layer was the moat. Nine runs later it ships as a product, repeatedly:
- **Coach AI** — "transforms raw VALORANT match data into actionable
  coaching insights in seconds … raw GRID data to coach-ready insights in
  a single API call with 80+ automated issue detections." That *is*
  ReplayCoach's core, coach-facing.
- **valocoach.ai** — "AI-powered Valorant coaching & match analysis: your
  gameplay has patterns, we read them."
- **iTero (itero.gg)** — League of Legends AI coach.
- **Cloud9 Assistant Coach** — AI analytics on the GRID match API for
  coaching staff.
- **Insights.gg / Coachable.gg** — auto-capture + VOD-review tooling.

Worse, the *demand side* is being eroded for free: **Mobalytics** ($0 AI
coach across League/Valorant/TFT) and **Blitz.gg** (free live in-match AI
coaching) give players automated coaching directly — shrinking the reason
to pay a human coach at all, and with it the coach's own budget for a tool.
This is the "incumbent ships it + free undercut" pattern (cf. Circle #8,
Bakesy #12), now hitting a persona whose own revenue the free tools attack.

**Verdict: KILL.** The factory's strongest-ever WTP lead decayed on BOTH
its gating question and the competitive landscape — exactly the PolicyDiff
lesson from Run #13: parked ≠ preserved. (Hotbox 3 → 2.)
